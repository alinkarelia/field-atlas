# Установка «Полевого атласа» через Sideloadly

Для личной установки подойдёт Windows и Sideloadly с бесплатным Apple ID. Mac и платная подписка Apple Developer для этого способа не обязательны. По [инструкции Sideloadly](https://sideloadly.io/) бесплатная подпись действует 7 дней; обновляйте её через функцию автоматического переподписания.

## Установка

1. Возьмите `FieldAtlas-unsigned.ipa` из успешной сборки GitHub → Actions → `Field Atlas build and checks` → пакет `field-atlas-native-iPhone`. ZIP сначала распакуйте. Нужен IPA для iPhoneOS, не приложение для симулятора.
2. Подключите разблокированный iPhone/iPad кабелем к Windows и подтвердите доверие компьютеру на устройстве.
3. Откройте установленный Sideloadly, выберите устройство, перетащите IPA. Войдите в свою учётную запись Apple непосредственно в программе и запустите установку.
4. Если iOS попросит доверие разработчику, подтвердите свой профиль в настройках устройства. Для приложения, подписанного для разработки, включите «Настройки → Конфиденциальность и безопасность → Режим разработчика» и подтвердите перезапуск. Пункт может появиться после установки. [Пояснение Apple](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device/).
5. Откройте «Полевой атлас». Требуется iOS/iPadOS 17 или новее. Для съёмки нужен аппаратный LiDAR; устройство без него позволяет вести карточки, но не должно предлагать действующую LiDAR-съёмку.

Если Sideloadly не видит устройство на Windows, проверьте драйверы и требования к iTunes/iCloud на его официальном сайте. Установка самим пользователем и запуск на физическом телефоне ещё не подтверждены результатами облачного симулятора.

## Обновление и материалы

При обновлении используйте ту же учётную запись и прежние настройки идентификатора приложения. Исходный Bundle ID — `ru.archiverf.fieldatlas`. Не меняйте его и не удаляйте приложение ради обновления: материалы хранятся внутри приложения.

Перед первым полевым выходом и перед обновлением скопируйте каталог «На моём iPhone → Полевой атлас → FieldAtlas» из приложения «Файлы». В нём находятся `state.json`, исходные файлы `assets/` и незавершённые обходы. Каталоги с `UITests` используются только облачными DEBUG-тестами и в Release не создаются.

## Первая проверка на телефоне

- Создать пробный проект и карточку, закрыть приложение, открыть снова и проверить текст и фото.
- Снять небольшой фрагмент на безопасном участке, сохранить и вновь открыть проект; оценить привязку и видимость покрытия.
- Для помещения снять одну комнату с дверью и окном, проверить соответствие подписей и размеров контрольному замеру.
- Проверить сохранение при переходе в фон, повороте экрана и временном отсутствии сети.

В приложении доступен вход через учётную запись archiverf.ru: кнопка профиля → «Войти через сайт». На сайте можно создать пароль через подтверждение почты, затем использовать почту и этот пароль. Защищённое окно возвращает приложение в тот же аккаунт. Допуск к рабочим заданиям назначается на сайте; пароль сам по себе не расширяет права.

Передача съёмок в рабочий сайт, Google Drive и обработка x0 ещё требуют отдельного подключения. Вход не запускает загрузку материалов. Локальная работа доступна без этих подключений.

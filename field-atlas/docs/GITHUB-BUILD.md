# Сборка в GitHub

Рабочая ветка: [codex/field-atlas-20261125](https://github.com/alinkarelia/atlas-ios/tree/codex/field-atlas-20261125/field-atlas). Изменения собраны в [PR № 1](https://github.com/alinkarelia/atlas-ios/pull/1) закрытого репозитория `alinkarelia/atlas-ios`. Папка `field-atlas/` содержит текущий проект. Исходники TerraView в остальных папках и прежние выпуски сохранены.

## Что делает workflow

1. На Linux устанавливает фиксированные зависимости, проверяет JavaScript, Python и рабочие сценарии браузера.
2. На macOS запускает Swift-тесты общей библиотеки, создаёт проект Xcode и компилирует нативное приложение.
3. На доступных симуляторах iPhone и iPad проверяет четыре типа проектов, карточки, поворот и сохранение после перезапуска. Снимки экранов прикладываются к результату XCTest. iPhone и iPad выполняются параллельно; их отчёты сохраняются в отдельных пакетах. Реальный Keychain проверяется тестом записи, чтения, обновления и удаления пробной сессии.
4. После успешных проверок собирает Release для iPhoneOS, формирует **неподписанный** `FieldAtlas-unsigned.ipa` и SHA-256.

Workflow использует только `contents: read`; автоматической публикации в App Store, TestFlight или на сайт нет. Локальная база `.runtime`, пользовательские фотографии и ключи сервисов в GitHub не передаются. Тесты используют временные базы, а DEBUG-сессии iOS получают отдельный каталог с UUID без удаления пользовательского каталога.

Тестовый запуск в симуляторе не подтверждает работу физического LiDAR, камеры, GPS, барометра и точность измерений. Неподписанный IPA нельзя напрямую установить обычным нажатием на iPhone или отправить в TestFlight: потребуется подпись подходящим сертификатом и отдельная приёмка на устройстве.

В GitHub откройте вкладку Actions → `Field Atlas build and checks` → нужный запуск. Внизу успешного запуска доступны пакеты `field-atlas-browser-reports` и `field-atlas-native-iPhone`. Смотрите commit SHA: результат старой сборки не относится автоматически к последующим изменениям. Срок хранения артефактов настроен на 14 дней.

## Основания

- [GitHub: облачные исполнители, включая macOS](https://docs.github.com/en/actions/reference/runners/github-hosted-runners).
- [Apple: аргументы запуска UI-тестируемого приложения](https://developer.apple.com/documentation/xcuiautomation/xcuiapplication/launcharguments).

Фактически полученные результаты и идентификаторы сборок фиксируются отдельно в `reports/GITHUB-VERIFICATION.md` после проверки артефактов.

# Геология и недра в Полевом атласе

Решение от 27 ноября 2026. Это проект раздела и проверка источников, не отчёт о загруженной базе месторождений.

Отдельный вход «Геология», общая карта и общий каталог регионов. Пользователь выбирает территорию и включает нужные слои. Скачать геологический пакет можно отдельно от дорожной карты: отсутствие геологического пакета не мешает обычной карте работать офлайн. Автоматически загружать все области не нужно.

## Слои и смысл объектов

| Слой | Что показываем | Что нельзя подменять |
|---|---|---|
| Месторождения | Название, сырьё, степень изученности, состояние по источнику | Точку месторождения нельзя считать точной границей рудного тела |
| Проявления и находки | Описанные проявления минералов и отдельные полевые находки | Проявление не означает промышленные запасы |
| Геологическое строение | Породы, возраст, разломы, четвертичные отложения | Масштаб карты не равен точности GPS |
| История добычи | Старые рудники, карьеры, штольни, заводы, архивные карты | Историческое состояние не описывает современный доступ |
| Недропользование | Участки лицензий и аукционов с датой актуальности | Участок лицензии не равен месторождению |
| Свои наблюдения | Фото породы, точка/контур, маршрут, описание и образцы | Предположение волонтёра не становится установленным составом породы |

Фильтры: регион, группа сырья, тип объекта, период, источник, степень проверки. Перекрывающиеся объекты объединяются в группу на мелком масштабе. Приблизительные координаты отображаются с областью неопределённости. Для пустого слоя показывается «Нет загруженных данных», а не «Месторождений нет».

## Проверенные источники

- [Роснедра: карта участков для лицензирования](https://rosnedra.gov.ru/press/news/uchastki-nedr-dlya-litsenzirovaniya-teper-na-odnoy-karte/). Официальное сообщение описывает карту аукционных участков, виды сырья и статусы. Подходит для отдельного слоя недропользования; не является полной картой месторождений.
- [ТФГИ по СЗФО: онлайн-ресурсы Росгеолфонда](https://tfgi-szfo.ru/online-resurs.html). Есть ссылки на кадастр месторождений, баланс запасов, лицензии и каталог геологических документов. Это точка входа для проверки первичных сведений по северо-западным регионам. Условия доступа к конкретному документу проверяются отдельно.
- [Каталог пространственных данных Государственного геологического музея РАН](https://maps.geologyscience.ru/geonetwork/srv/rus/catalog.search). Каталог метаданных помогает найти карты и их правообладателей. Наличие записи в каталоге само по себе не означает разрешение встроить или распространять карту.
- [Институт геологии КарНЦ РАН: экспозиции](https://geoserv.krc.karelia.ru/index.php/exposition). Описаны геологические карты Карелии, месторождения облицовочного камня и исторические объекты. Использовать как источник описаний и указатель на научные материалы, а не как готовый API координат.

Прямые сайты Росгеолфонда, geolkarta.ru и часть страниц института Карпинского при проверке отвечали с тайм-аутом. Рабочий публичный API массовой выгрузки и право на перепубликацию всей базы не подтверждены. Сбор произвольных точек из непроверенных каталогов не выполнялся.

Международные решения также проверены:

- [GTK, база и карты Фенноскандии / Nordic Ore Deposit Database](https://www.gtk.fi/en/fennoscandian-mineral-deposits-application-ore-deposits-database-and-maps/). Полезен сам формат: шахты, месторождения, проявления, история добычи, геология и качество исходных сведений. Российскую часть перестали обновлять с 24 февраля 2022 года; современная база перечисляет другие страны. Старые совместные карты могут быть научным источником по Северо-Западу, но их нельзя выдавать за актуальную базу России. Для конкретной старой выгрузки ещё требуется проверить состав и лицензию.
- [GTK: WMS/WFS](https://www.gtk.fi/en/services/data-sets-and-online-services-geo-fi/interface-services/) — пример подключения внешних слоёв по стандартным интерфейсам. Условия использования различаются по слоям, поэтому разрешение на онлайн-просмотр и разрешение включить данные в наш офлайн-пакет учитываются раздельно.
- [OneGeology](https://onegeology.org/) — полезная архитектура каталога геологических слоёв и метаданных, однако на официальном сайте опубликовано сообщение о закрытии инициативы. Брать её как гарантированно работающую внешнюю подложку нельзя. Документацию стандартов и доступные данные отдельных поставщиков можно изучать независимо.
- [USGS MRDS](https://mrdata.usgs.gov/mrds/) при прямой проверке вернул 403; доступность выгрузки и полнота сведений по нашим регионам в этом этапе не подтверждены.

## Общая модель приложения и сайта

Каждый физический объект получает постоянный UUID, после принятия сервером — короткий код общего реестра. Карточки обследований имеют собственные номера. У одного рудника могут быть геологическая карточка, историческая справка, несколько съёмок и маршруты; это связи одного объекта, а не повторяющиеся метки.

Для импортированного объекта хранятся: `sourceDatasetID`, `sourceObjectID`, название источника, ссылка на документ/лист, дата исходных сведений, дата получения, лицензия, исходная система координат, масштаб, метод привязки, оценка точности и статус проверки. Геометрия для отображения — WGS84; исходная геометрия сохраняется отдельно. Импорт обновляется по паре источник + исходный ID, не по похожему названию.

Геологическая карточка: тип объекта, названия и прежние названия, сырьё по справочнику, вмещающие породы, возраст, описание, доказательства, история наблюдений. Количества запасов и категории воспроизводятся только с конкретной датой и источником. Неизвестное остаётся неизвестным.

Исторические растровые карты проходят тот же процесс привязки, что карты Мариинки: исходный лист, система координат/контрольные точки, модель преобразования, остаточные ошибки, область достоверной привязки. Ручная карта не растягивается до внешнего совпадения без сохранения погрешности.

Серверный пакет региона: версии векторных слоёв, привязанные растры, легенды, источники, лицензии и SHA-256. Хранение на Google Диске Al In, доставка через сервер без передачи токенов Google клиенту. Офлайн скачивается выбранный регион и выбранные темы; обновления не меняют локальные наблюдения.

## Порядок внедрения

1. Завершить общую карту, добровольную загрузку регионов и надёжную передачу собственных съёмок.
2. Собрать проверенный пилот по Карелии: ограниченный набор научно описанных геологических и историко-горных объектов, с источниками и разрешёнными геоданными.
3. Проверить формат импорта, лицензии и точность координат; только после этого выпустить тематический слой и офлайн-пакет.
4. Расширять на остальные согласованные регионы тем же процессом, показывая полноту и дату каждого набора.

# Общий вход сайта и приложения

На archiverf.ru установлен вход по почте и паролю. Первый пароль или восстановление: «Войти» → «Создать или восстановить пароль» → код из письма → новый пароль. В своей учётной записи: «Настройки» → «Личная информация» → «Вход в учётную запись» → «Создать или изменить пароль».

Приложение открывает защищённое окно сайта через ASWebAuthenticationSession. Сайт возвращает одноразовый код, связанный с PKCE S256 и случайным состоянием. Приложение меняет его на отзываемую сессию, хранит только её в Keychain и загружает доступные задания. Пароль, код из письма и PKCE verifier не сохраняются.

Существующие разрешения сайта действуют и в приложении. Для рабочего подключения Atlas руководитель должен назначить доступ к проекту. Локальные съёмки и карточки доступны без входа; вход не передаёт файлы автоматически.

На сервере пароль хранится как Argon2id-хеш с индивидуальной солью. Для создания и восстановления требуется свежее подтверждение почты; для обычной смены — действующий пароль либо такое подтверждение. Смена отзывает остальные браузерные и нативные сессии. Добавлены ограничения частоты, размера и времени чтения запросов.

Проверено 25.11.2026: 12 интеграционных сценариев на свежем коде сайта, включая обмен PKCE, повторно в изолированном Linux-образе; 14 браузерных проверок, в том числе ширины 320/390/844/1280. Установка и HTTPS-форма проверены на рабочем сайте. Реальные пароли пользователей при испытаниях не задавались. Вход с физического iPhone и доступность Keychain после подписи Sideloadly требуют проверки на устройстве.

# Полевой атлас

Нативное приложение iPhone/iPad для полевых исследований: помещения, фасады, участки и кладбища. Исходники, локальная песочница, сервер для разработки и тесты.

## Состояние разработки

Проект активно дорабатывается. Проверки симуляторов не подтверждают работу физического LiDAR/GPS. Реализованы вход через сайт, передача оригиналов и снимка карточек в выбранное задание, запросы к серверному x0. Это не означает автоматического создания людей или объединения графовых связей: снимок карточек пока передаётся как JSON-материал. Автоматическая отправка в Google Drive ещё не подключена. Данные людей и съёмок в этот репозиторий не входят. Примеры в examples — синтетические.

## iOS

Нужны macOS, Xcode с iOS 17+, XcodeGen. В каталоге field-atlas/ios выполните xcodegen generate и откройте FieldAtlas.xcodeproj.

Стандартные GitHub Actions выполняют тесты общей логики, проверки интерфейса на симуляторах iPhone/iPad и выпускают неподписанный IPA. Для установки требуется подпись Apple.

## Песочница

В каталоге field-atlas установите зависимости: python -m pip install -r requirements.txt.
Запустите: python -m server.app --port 8879.
Открыть http://127.0.0.1:8879. Сервер предназначен для локальной разработки.

## Сохранность данных

Исходники фотографий и измерений сохраняются отдельно. Нечитаемые надписи и неподтверждённые связи требуют проверки человеком. Отдельные координатные системы не объединяются без подтверждённой привязки. Телефонный LiDAR не определяет подземные захоронения.

## Зависимости

MapLibre Native iOS (лицензии поставщика сохраняются), Apple ARKit/RoomPlan/CoreLocation/Vision. Использование Apple SDK регулируется условиями Apple. Публичный доступ к репозиторию сам по себе не назначает лицензию на код.
